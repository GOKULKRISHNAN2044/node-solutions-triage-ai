# 🧠 node-solutions-triage-ai

> AI-powered Request Triage Assistant — Built for the Node Solutions Technical Challenge (Stage 2)

---

## Overview

A full-stack AI tool that turns unstructured business requests into clear, actionable triage results in seconds.

**Stack:** Python FastAPI · React JS · Gemini 2.5 Flash · SQLite

---

## What It Does

| Input | Output |
|-------|--------|
| Any raw business request (email, form, chat) | Summary · Category · Priority · Routed Team · Draft Response |
